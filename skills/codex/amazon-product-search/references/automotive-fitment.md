# Automotive Fitment Verification

Use this checklist whenever the Amazon product is a vehicle part or fitment affects the recommendation.

## Identify the exact vehicle

Record every relevant discriminator before drawing conclusions:

- model year, make, and model
- engine family, displacement, fuel type, aspiration, and emissions configuration
- trim, body style, cab/bed, chassis or platform, and build-date split
- 2WD/4WD/AWD and transmission when relevant
- market/region and left- versus right-hand drive when relevant

Ask only for a missing discriminator that materially changes the result and cannot be reasonably resolved from context.

## Establish authoritative anchors

Search for and reconcile:

1. OEM catalog entries and diagrams
2. original and superseding OEM part numbers
3. manufacturer application guides and installation instructions
4. dimensions, mounting points, connector counts, molded features, and other physical identifiers
5. explicit engine, drivetrain, trim, build-date, or region exclusions

Treat title year ranges and Amazon''s vehicle selector only as leads. A broad title is not proof of fitment.

## Inspect construction and identity

- Compare listing photographs with OEM diagrams and known-original photos where available.
- Distinguish molded/formed parts from flat, generic, universal, or cut-to-fit material.
- Check contours, reliefs, heat-shield locations, fastener holes, edge shapes, backing, thickness, and included clips or hardware.
- Detect rebrands using matching photos, dimensions, mold marks, packaging, claim wording, model numbers, and review photos.
- Label shared-product conclusions as inference unless manufacturer or catalog evidence confirms them.

## Classify each candidate

Use one of these statuses:

- **Compatible**: authoritative application data or exact OEM interchange supports the full vehicle configuration and no exclusion conflicts.
- **Incompatible**: an authoritative exclusion, wrong interchange, or physical conflict applies.
- **Questionable / not verified**: the listing claims fit but engine/trim details are absent, sources conflict, or only the Amazon selector/title supports it.

State the specific reason. Never collapse gas/diesel, 2WD/4WD, generation, build-date, or chassis distinctions without evidence.

## Decide value

Compare the cheapest verified-compatible option with stronger alternatives. Consider molded accuracy, material, thermal/acoustic function, hardware, warranty, return friction, evidence quality, and price. Recommend a premium only when its advantage is meaningful and supported.
